Bundled fonts for HomeDock's "Schriftart" / Font setting
========================================================

The TV firmware ships a single font family, so CSS font keywords all fall back
to it. These self-hosted Latin-subset woff2 files are what makes the Font
setting actually change the look on the TV.

All three are licensed under the SIL Open Font License v1.1 (see OFL.txt):

  Playfair Display  (classic / serif)   Copyright The Playfair Project Authors
                    https://github.com/googlefonts/Playfair
  Comfortaa         (rounded)           Copyright The Comfortaa Project Authors
                    https://github.com/alexeiva/comfortaa
  Roboto Mono       (monospace)         Copyright The Roboto Mono Project Authors
                    https://github.com/googlefonts/robotomono

woff2 files are the Latin subset (static, one file per weight) from Fontsource
(https://fontsource.org). Weights: Playfair 400/600, Comfortaa 300/600,
Roboto Mono 300/600.
