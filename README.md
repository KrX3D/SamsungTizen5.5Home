# HomeDock

A minimal, Apple-TV-style home screen for Samsung Tizen TVs.

- Rotating full-HD nature wallpapers (Wikimedia Commons, credited on screen)
- Clock, date, current weather and 7-day forecast ([Open-Meteo](https://open-meteo.com), no API key)
- A dock of your apps with their real icons
- English and German, following the TV's language

Tested target: Tizen 5.0 (2019 models). The code is ES5 and avoids CSS newer than Chromium 63.

## Remote

| Key | Action |
|---|---|
| Down / Up | Move between the dock and the sources row |
| Left / Right | Move through the dock or the sources row |
| OK | Open the app, or open the app picker on **+** |
| Hold OK | On an app: **Move** / **Remove**. On a source: **Rename** / **Hide** |
| Red | Settings (grouped): name/clock, current weather + 7-day forecast separately, wallpaper, photo credit, sources |
| Back | Leave HomeDock |

The weather location is picked from a list (country, state, district, first letter, place)
covering 26 countries, every German village included, or found by typing a name. The list
reopens at the last pick; Back steps up a level.

The wallpaper can rotate through the bundled photos, show one chosen photo, or be one of
several plain colour backgrounds (light, mist, sand, dark, dusk, ocean) that never change.

When the TV reports HDMI inputs, a sources row appears under the dock; OK switches to an
input. Hidden sources can be brought back from Settings.

HomeDock ships a boot service that tries to open it after the TV powers on, with no PC
needed. Whether on-boot services run is firmware-dependent, so if it does not start on
your TV, open HomeDock last and enable **Settings > General > Smart Features > Autorun Last App**,
or run a PC-side launch-on-wake watcher. Pressing Home still opens Samsung Home.

## Install

Add `KrX3D/SamsungTizen5.5Home` under **Saved Repos** in TizenBrew Installer and install it from there.
Updates arrive the same way.

Or install a release by hand with Tizen's `sdb`:

```
sdb connect <tv-ip>
sdb -s <tv-ip>:26101 install HomeDock.wgt
```

Uninstall: `sdb -s <tv-ip>:26101 uninstall krx3dLnch1`

## Build

Every push to `main` that changes `app/` builds, signs and releases `HomeDock.wgt`
(`.github/workflows/build-release.yml`). It needs two repository secrets:

- `TIZEN_AUTHOR_KEY`: base64 of the author `.p12`
- `TIZEN_AUTHOR_KEY_PW`: its password

Always sign with the same author certificate. The TV rejects an update signed by a different author.

Wallpapers are refreshed with `python scripts/fetch-wallpapers.py app/assets/wallpapers app/js/wallpapers.js`.

`app/places/` is generated by `scripts/build-places.py` from GeoNames
([dump](https://download.geonames.org/export/dump/), CC BY 4.0: `cities1000.txt`, `DE.txt`,
`admin1CodesASCII.txt`, `admin2Codes.txt` in one folder):
`python scripts/build-places.py <that folder> app/places`.
`app/icon.png` comes from `python scripts/make-icon.py app/icon.png`.
